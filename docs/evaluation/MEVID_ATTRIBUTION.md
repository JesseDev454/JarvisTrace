# MEVID / MEVA attribution

G507 source footage was provided locally by the user. Sources and derived previews
remain local; no surveillance footage or person-identity annotations are uploaded
or committed. Derived MP4 clips are time crops/re-encodings with audio omitted;
source AVI bytes remain unchanged. This project evaluates portable-object
retrieval, not facial recognition or person identity matching.

The official [MEVID repository](https://github.com/Kitware/MEVID) describes MEVID
as annotations on MEVA footage. The official [MEVA dataset site](https://mevadata.org/index.html)
provides dataset citations and identifies the video data license as CC BY 4.0.
See the repository's [MEVA data license](https://github.com/Kitware/MEVID/blob/main/MEVA-data-license.txt)
for the source terms. This note records attribution; it does not redistribute data.

Suggested bibliography entries:

- Daniel Davila et al. **MEVID: Multi-view Extended Videos with Identities for Video
  Person Re-Identification.** IEEE/CVF WACV, 2023.
- Kellie Corona, Katie Osterdahl, Roderic Collins and Anthony Hoogs. **MEVA:
  A Large-Scale Multiview, Multimodal Video Dataset for Activity Detection.**
  IEEE/CVF WACV, 2021, pp. 1060–1068.
