# Stage 9 object-state analysis implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline. Steps use checkbox syntax for tracking.

**Goal:** Convert preserved ByteTrack text labels into auditable timestamped
backpack trajectories and conservative image-coordinate summaries.

**Architecture:** Pure standard-library import/analysis in `src/object_state.py`;
OpenCV metadata and file output in `src/stage9.py`. Existing stages, APIs, model
instances and databases remain independent.

**Tech Stack:** Python 3.13, unittest, installed OpenCV; no new dependencies.

**Spec:** Current user master brief, `docs/PROJECT_AUDIT.md`, `docs/ARCHITECTURE.md`.

## Global constraints

- Preserve existing source, data, labels and uncommitted work.
- No database changes, GPU inference, new downloads or automatic identity merges.
- Six columns mean untracked detection with confidence; seven include a local ID.
- Label suffixes are one-based, stride-one video frame numbers; timestamps are
  `(suffix - 1) / fps`. Reject invalid, ambiguous and duplicate tracked observations.
- Missing label files mean no exported observation; never infer physical absence.
- Report normalized center extent and net displacement, contiguous gaps, local
  windows, unresolved nearby fragments and all latest observed candidates.
- Low displacement is an image-space candidate only, under an explicitly declared
  static-camera assumption. All detector observations remain unreviewed.
- Fresh output directories only; do not overwrite previous results.

## Review focus

- Off-by-one/numerically sorted labels: fixture has frames 1, 2, 10 with literal times.
- Bad/mixed export formats: reject NaN, bad confidence/boxes/IDs and repeated IDs/frame.
- Slow drift or missed frames: test extent-based windows and gap segmentation.
- Multiple objects/untracked detections: no cross-ID merging or unique final identity.
- File side effects and missing metadata: input hashes stable; output reuse rejected.
