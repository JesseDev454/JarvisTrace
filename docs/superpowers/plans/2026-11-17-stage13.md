# Stage 13 G507 Evaluation Plan

**Goal:** Inspect real G507 CCTV, prepare independent-review evidence and run only
defensible evaluation/smoke tests using the existing retrieval implementation.

**Architecture:** Local reproducible inventory/clip tooling and an evaluation
manifest layered on Stage 10/11. Proposed human-readable labels stay distinct from
verified ground truth. No predictions become ground truth. No model downloads,
retraining, original recording edits or surveillance uploads.

## Findings and scope

- Actual folder contains 11 AVI files: the specified nine morning recordings and
  two additional afternoon recordings. Inventory all, primary clips use morning.
- First probe: H.264, 1920×1072, 30 fps, 9000 frames / 300 seconds. Filename times
  are local/unspecified timezone; do not invent UTC or exact capture continuity.
- Stage 10 can reuse OpenCV decoding and CLIP batching. Stage 11 combines separate
  CLIP and provenance-qualified MiniLM rankings. G507 has no reviewed descriptions
  yet, so missing text coverage must be reported rather than invented.
- Existing working source is uncommitted from Stages 11/12; preserve it and the
  unrelated prototype helper tests. No push or automatic full-dataset GPU run.

## Decisions

- Originals and derived footage stay in ignored local datasets/outputs folders;
  reusable scripts, tests, blank schemas and written reports can be versioned.
